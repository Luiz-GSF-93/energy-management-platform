# F1.64 — Invoice quarantine

Distributor invoices remain quarantined after byte verification. A service-only view exposes receipt/review/rejection states without allowing financial import. The worker stores an immutable intake assessment together with the provider result, bound to organization, document hash, customer, unit and reference month. Historical assessments remain readable when new OCR requests are disabled; later registration edits do not silently change the decision. Missing linked registrations reject automation.

Validation: 225 OCR/documents tests, 20 database quarantine checks, backend/frontend builds and document-page lint passed. The production view migration was applied. The previously authorized Festball negative test was preserved through queue transitions with explicit replay provenance, no additional Azure request and no financial writes. Its stored state is REJECTED and canImport is false. General OCR remains disabled.
