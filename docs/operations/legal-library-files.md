The 31-reference legal catalogue is global; private client contracts and findings remain tenant scoped. Public original preservation reuses the existing Owner source registry and private Azure Blob. Source registration is not normative publication. Existing independently reviewed corpus and composite publication guards remain unchanged.

Migrations 335/336 expand primary public authorities, add immutable page indexes bound to a verified PRESERVED storage operation, and deny direct table access. The source revision, storage operation and active canonical Owner remain mandatory. Search rechecks the actual organisation license/permissions and active original/source state, returns at most four chunks, and exposes no blob keys. Context is marked PRESERVED_CONTEXT_NOT_NORMATIVE_REVIEW and cannot create a law citation or increase normative coverage.

The report snapshots files actually supplied to each interpretation, page, edition, original hash and capture date. Q&A searches stored contract text and official files without new OCR or a new document credit; the existing AI budget remains enforced. A later question never rewrites the archived report. Capture does not establish currency, consolidated amendments, binding precedent status or applicability. EPE studies, ONS operation reports and catalogue indexes are not legislation.

## Explicit maintenance

1. Run `python scripts/legal-public-files-download.py` in an isolated maintenance checkout. Explicit public PDFs only; no credentials, challenges or arbitrary URL crawl. Review pending errors.
2. Build backend. With the existing service environment and an active canonical Owner UUID, run `node scripts/preserve-legal-library.cjs OWNER_UUID /tmp/energy-legal-official-files-20261117/download-manifest.json`. Do not bootstrap AppModule or duplicate workers. Never print environment secrets.
3. The local state file saves request IDs before writes. An uncertain blob receipt stops that entry; reconcile the recorded operation before another upload. Successful reruns reuse hashes and index operations. The script does not approve norms, contracts or financial records and does not call OCR/AI.
4. Existing REN 1000 and CCEE procedure originals are reused. Native text is bounded to 1000 pages/7.5 MB and indexed by page. Image-only pages remain identified, not invented. Old/inapplicable materials require curation rather than being silently treated as current law.

Rollback: disable LEGAL_AUDIT_ENABLED and LEGAL_AUDIT_WORKER_ENABLED; retain immutable originals, completed blocks, reports, credits and indexes. Compatible existing invoice routes and license calculations remain in place.
