# Busca de biblioteca por unidade e competência

A biblioteca em Contratos → Parâmetros de cálculo permite buscar e preencher tarifas pela unidade e competência. O operador não precisa selecionar cada lançamento. Usa somente a última revisão de cada perfil e exige correspondência única de distribuidora, grupo, subgrupo, modalidade, classe e cobertura de todo o mês. Categoria permite resolver ambiguidades. Nunca reaproveita silenciosamente uma revisão superada, prolonga vigência ou troca de distribuidora.

A seleção abre o fluxo existente, preenchendo tabela e datas do mês. A declaração tributária, prévia, aplicação atômica/idempotente, autor, versão e aprovação permanecem no backend existente. Tarifas históricas ainda exigem justificativa. Unidade ACR continua exigindo preço ACL documentado. Esta entrega automatiza a localização e o preenchimento; não aplica tarifas automaticamente ao terminar OCR e não conclui a homologação financeira da Cenourão.

Validação: teste de correspondência, ambiguidade, revisão, calendário, vigência, enquadramento e dados ausentes; build frontend. A biblioteca precisa conter tabela CPFL aplicável e o cadastro da unidade precisa estar completo. API CCEE permanece posterior.
